# Функционал сайта Repetitor

Полное описание функциональности: роли пользователей, разделы сайта, экраны, сценарии
и правила доступа. Схема данных описана в [DATABASE.md](./DATABASE.md), полный контракт
API — в [openapi.yaml](./openapi.yaml), краткая карта маршрутов — в разделах 12–13
этого документа и в [../docs/API.md](../docs/API.md).

- **Продукт:** веб-сервис для изучения иностранных языков (словарь, SRS-практика, курсы, AI-репетитор)
- **Роли:** `Learner` (ученик), `Teacher` (учитель), `Admin` (администратор платформы)
- **Клиент:** SPA (React 19 + Vite), маршруты `/login`, `/admin`, `/courses`, `/groups` и др.
- **Сервер:** ASP.NET Core 10, префикс API `/api/v1`, авторизация JWT (access + refresh)
- **Схема БД:** см. `DATABASE.md`

## Обзор разделов

```
Публичная часть (без авторизации)
  Вход · Регистрация (Learner / Teacher) · Сброс пароля

Ученик (Learner)                        Учитель (Teacher)
  Дашборд                                 Курсы: мои курсы и уроки
  Каталог курсов и уроков                 Публикация / снятие с публикации
  Мои слова                                Генерация контента через ИИ
  Словарь (поиск, импорт, W-o-D)          Учебные группы:
  Практика (SRS)                            • участники: email и код-приглашение
  Упражнения                                • персональные занятия (1 участник)
  Грамматика                                • назначение курсов с авто-зачислением
  Мои группы (вступление по коду)

Администратор (Admin)
  Пользователи (роли, блокировка) · Статистика · Курсы и уроки платформы
  AI-настройки и провайдеры · Журнал AI-вызовов · Реиндексация словаря
```

Возможности, доступные через API, но пока без экранов в интерфейсе: AI-репетитор
(чат со стримингом), синтез и распознавание речи, оценка произношения, колоды карточек.

## 1. Аккаунты и аутентификация

| Возможность | Описание |
|---|---|
| Регистрация | Email, имя, пароль (≥ 8 символов), изучаемый и интерфейсный языки, уровень CEFR, дневная цель в XP. Роль на выбор: `Learner` или `Teacher`. Роль `Admin` при регистрации недоступна |
| Вход | Email + пароль; при входе фиксируются `LastLoginAt` и `LastActivityDate` |
| Токены | Access JWT (короткоживущий) + refresh-токен с ротацией и отзывом; есть выход из всех устройств |
| Смена пароля | Требуется текущий пароль; после смены прежние сессии остаются действующими до явного выхода |
| Восстановление пароля | `forgot-password` принимает email всегда (202 без утечки существования ящика), `reset-password` принимает одноразовый токен |
| Профиль | Имя, аватар, изучаемый язык, уровень и целевой уровень, дневная цель, скорость озвучки, подсказки и уведомления |
| Блокировка | `IsActive = false` — мягкая блокировка: вход запрещён, данные сохраняются |

**Правила:** refresh-токен хранится в виде SHA-256 хеша; пароли — BCrypt (work factor 12);
интерфейсные языки: русский и английский.

## 2. Роли и доступ

| Раздел | Learner | Teacher | Admin |
|---|---|---|---|
| Каталог, словарь, практика, упражнения, репетитор, произношение | ✅ | ✅ | ✅ |
| `GET /catalog/*` без токена | ✅ (без прогресса) | ✅ | ✅ |
| Свои курсы и уроки (`/teacher/*`) | ❌ 403 | ✅ | ✅ |
| Курсы и уроки платформы (`/admin/courses`, `/admin/lessons`) | ❌ 403 | ✅ | ✅ |
| Учебные группы (`/teacher/groups/*`) | ❌ 403 | ✅ | ✅ |
| Мои группы (`/groups`, `/groups/join`) | ✅ | ✅ | ✅ |
| Администрирование: пользователи, статистика, AI-настройки и журнал, реиндексация (`/admin/*` кроме курсов и уроков, `POST /ai/dictionary/reindex`) | ❌ 403 | ❌ 403 | ✅ |

**Изоляция данных:** учитель видит и изменяет только свои курсы, уроки и группы.
Администратор видит все сущности всех владельцев. Курсы и уроки, принадлежащие учителю,
помечены в ответе флагом владения (`ownerDisplayName` / `isOwnCourse`).

## 3. Дашборд и статистика

| Элемент | Содержание |
|---|---|
| Сводка | Карточки к повторению, новые слова, всего слов, освоено слов, упражнений за 7 дней |
| Цель дня | Накопленный XP, дневная цель в XP, отметка достижения цели |
| Серия | Текущая и максимальная серия дней подряд, календарь активности за период |
| Рекомендации | Слова, подобранные под текущий уровень и цели |
| Статистика | XP, повторения, верные ответы, новые слова, упражнения, минуты занятий по дням |
| Цель | Изменение дневной цели в XP |

Данные агрегируются в `user_daily_stats`, сводка — представление `vw_user_learning_summary`.

## 4. Каталог: курсы, уроки, грамматика

| Возможность | Описание |
|---|---|
| Языки | Список языков с флагом, названиями и подсказкой голоса TTS |
| Курсы | Фильтры по языку и уровню A1–C2; карточка показывает обложку, количество опубликованных уроков, оценку времени и процент прохождения |
| Доступ к курсу | Отмечается только опубликованный курс (`IsPublished`); прогресс и `isEnrolled` считаются по записям на курс |
| Уроки | Содержание в Markdown, ключевые слова, грамматическая тема, статус (`NotStarted` / `InProgress` / `Completed`), прогресс по урокам |
| Грамматика | Темы по языкам с объяснением в Markdown и минимальным уровнем |

**Важно:** самостоятельной записи на курс нет — запись (`course_enrollments`) создаётся
учителем при назначении курса группе (см. раздел 9). Поэтому в каталоге `isEnrolled`
и ненулевой прогресс появляются только после назначения курса.

| Слово дня | Случайное слово по уровню пользователя с озвучкой |
| Озвучка | Генерация аудио слова по TTS-провайдеру |

## 6. Практика (SRS)

| Возможность | Описание |
|---|---|
| Очередь | Количество карточек к повторению и разбивка по колодам/состояниям |
| Прогноз | Расписание повторений на несколько дней вперёд |

| Приостановка | Отдельная карточка может быть приостановлена и исключена из очереди |

## 8. AI-репетитор и произношение

Возможности раздела реализованы на уровне API (`/api/v1/tutor`, `/api/v1/speech`),
экранов в интерфейсе пока нет.
| Возможность | Описание |
|---|---|
| Сессии | Создание диалога с режимом: `FreePractice`, `LessonRoleplay`, `ExamPreparation`, `GrammarHelp`, `Interview`, `Travel` |
| Переписка | Отправка сообщений, ответ с учётом словаря пользователя (RAG) |
| Стриминг | Потоковый вывод ответа по Server-Sent Events |
| Управление | Перегенерация ответа, архивирование и удаление сессии, оценка сообщения, статистика расхода токенов |
| Синтез речи | TTS: озвучка слов, уроков и ответов репетитора с регулируемой скоростью |
| Распознавание | STT: расшифровка записи ученика |
| Оценка произношения | Баллы 0–100: overall, accuracy, fluency, completeness, prosody + попсловные баллы и рекомендации |
| Записи | Список записей пользователя с удалением |

## 9. Учитель: курсы и уроки

| Возможность | Описание |
|---|---|
| Свои курсы | Создание, редактирование, удаление, назначение языка, уровня, обложки, порядка |
| Публикация | Публикация и снятие с публикации: черновик учителя не виден в публичном каталоге |
| Свои уроки | Создание и редактирование уроков внутри своего курса, ключевые слова, привязка к теме грамматики |
| Генерация ИИ | Генерация урока и курса целиком по описанию, теме и длительности |
| Изоляция | Чужой курс или урок недоступны: 404/403, изменение невозможно |

Системные курсы (`OwnerUserId = NULL`) создаются администратором; учитель не может
изменять и удалять их.

## 10. Учебные группы и персональные занятия

Основной сценарий: учитель набирает учеников в группу и открывает им курсы.
Группа из одного участника — это персональные занятия с одним учеником;
отдельного типа группы в системе нет.

### Состав группы

| Способ | Описание |
|---|---|
| Добавление по email | Учитель вводит email — ученик должен быть зарегистрирован. Регистр не важен, повторное добавление не дублирует |
| Код-приглашение | Учитель создаёт код (срок действия и лимит применений, `0` — без ограничений), ученик вводит его на странице «Мои группы» и сразу получает курсы группы |
| Отзыв кода | Код можно отозвать до истечения срока и лимита; повторное вступление с отозванным или исчерпанным кодом — 400 |
| Исключение | Учитель исключает участника; уже выданные ему курсы и прогресс сохраняются |

### Курсы группы

| Правило | Описание |
|---|---|
| Что можно назначить | Собственные курсы учителя (в том числе черновики) и опубликованные системные курсы |
| Кому доступно | Назначение сразу выдаёт курс всем текущим участникам; новые участники получают его при добавлении или вступлении по коду |
| Видимость курса | Ученик видит курс в каталоге после публикации, даже если запись создана заранее |
| Снятие курса | Убирается из группы для будущих участников; уже выданные записи сохраняются |
| Удаление группы | Ученики теряют связь с группой, но сохраняют курсы и прогресс |

### Ограничения доступа

Учитель не может увидеть, изменить или удалить чужую группу, а ученик не может
обращаться к `/teacher/groups` — запрос завершается 403. Администратор видит все группы.

## 11. Администратор

| Раздел | Возможности |
|---|---|
| Пользователи | Постраничный список, поиск, изменение роли, мягкая блокировка и разблокировка |
| Статистика | Пользователи, активность, XP, курсы, подписки/цели, агрегаты по платформе |
| Курсы и уроки | Создание и публикация **системных** курсов и уроков, генерация через ИИ |
| AI-настройки | Провайдеры (OpenAI-совместимые, Ollama), модели чата и эмбеддингов, температура, лимиты, промпты |
| Проверка настроек | Тест доступности провайдера с замером задержки |
| Журнал AI | Вызовы, токены, задержки, ошибки, оценка стоимости; очистка журнала |
| Реиндексация | Перестроение эмбеддингов словаря и эмбеддингов карточек повторения |
| Лимиты | Настройки дневных лимитов AI-вызовов |

Настройки ИИ содержат ключи провайдеров и доступны только администратору — вкладка скрыта
у учителя в интерфейсе, а API возвращает 403.

## 14. Технические ограничения

- **Авторизация:** Bearer JWT; refresh-токен — отдельный секрет, передаётся в теле или заголовке `X-Refresh-Token`.
- **Ошибки:** единый формат ProblemDetails (`type`, `title`, `status`, `detail`, `instance`, `errors`).
- **Ограничение частоты:** 300 запросов в минуту на IP.
- **Пагинация:** `page` / `pageSize` с ответом `PagedResponse<T>`.
- **Идемпотентность:** повторное добавление ученика, повторное назначение курса и повторная выдача записи на курс не создают дублей.
- **Валидация:** ограничения длины и формата входных данных, slug курсов и уроков уникальны в пределах языка и курса.
- **Интерфейсные языки:** русский и английский, выбор сохраняется в профиле и в браузере.
